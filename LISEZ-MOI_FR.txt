JEU DES ANIMAUX DE LA FERME — HÉBERGEMENT POUR GOOGLE SITES

1) Placez vos fichiers MP3 dans CE MÊME DOSSIER que index.html.
   Le nom du fichier doit être exactement celui-ci :
     vache.mp3
     cochon.mp3
     cheval.mp3
     poule.mp3
     mouton.mp3
     chien.mp3
     coq.mp3
     chevre.mp3
     chat.mp3
     canard.mp3

2) Vous n'avez pas besoin d'ajouter les dix fichiers tout de suite.
   Commencez par vache.mp3. Les autres sons personnalisés seront prioritaires
   dès que le fichier correspondant sera ajouté. Tant qu'il n'existe pas,
   le jeu conserve ses sources audio de secours habituelles.

3) Téléversez index.html, ce fichier LISEZ-MOI et le ou les MP3 dans un dépôt
   GitHub PUBLIC. Gardez tous les fichiers à la racine du dépôt (pas dans
   un sous-dossier).

4) Dans GitHub : Settings > Pages > Build and deployment > Deploy from a branch.
   Choisissez la branche main et le dossier /(root), puis Save.
   GitHub affichera l'adresse publique du site après sa publication.

5) Testez d'abord le fichier audio avec cette adresse :
   https://VOTRE-PSEUDO.github.io/NOM-DU-DEPOT/vache.mp3
   Remplacez VOTRE-PSEUDO et NOM-DU-DEPOT par vos valeurs.
   L'adresse doit ouvrir le lecteur audio ou télécharger le MP3.

6) Dans Google Sites : Insérer > Intégrer > Par URL.
   Collez l'adresse de la page du jeu :
   https://VOTRE-PSEUDO.github.io/NOM-DU-DEPOT/
   Insérez le jeu, ajustez sa taille, puis publiez le site.

IMPORTANT
- Le dépôt doit être public pour que les visiteurs de Google Sites puissent lire
  les sons sans compte GitHub.
- Les fichiers déposés dans ce dépôt seront accessibles publiquement. N'y placez
  pas d'enregistrements privés ni de données concernant les élèves.
- Pour remplacer un son, téléversez le nouveau MP3 avec le même nom et remplacez
  l'ancien. Actualisez ensuite la page publiée.
- Ne collez pas le fichier MP3 dans l'éditeur de code de Google Sites et n'utilisez
  pas le lien de partage Google Drive comme source audio du jeu.

Le jeu utilise les MP3 personnalisés en priorité, sans demander CORS au serveur.
Il tente ensuite ses sources audio de secours existantes pour les autres animaux.
